## Here you will find all firmware related stuff  
## Down here are instructions to flash the stm32  

To flash it via **usb-c** u first need to put it into **bootloader** mode, you can achive that by pluggin it in while holding boot button.  
Once in bootloader mode open **STM32CubeProgrammer**, and click connect and connect the board.  
Now pretty much done upload the **.bin** file there and flash.  

To know if it flashed sucesfully theres a small blue LED that will blink if flashed sucesfully.
Thats all.
